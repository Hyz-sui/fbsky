About This Site

This tool provides Bluesky preview cards that can be displayed on social media and other platforms.

Bluesky link previews fail to display correctly when posted on X. By using this site, you can display preview cards that include post content.

This can be used on X as well as on other sites.

Usage

Enter a Bluesky URL in the converter on the Home, click "Copy Embedding URL", and copy the generated URL.

You can customize the display format of the preview card before copying.

When you post the copied URL on X or other platforms, the preview card will be displayed.

The following URLs are currently supported:

  • User profiles (e.g. https://bsky.app/profile/hyzsui.com, https://bsky.app/profile/did:plc:plvfzwfp73ezywxils6e6u2n)
  • Posts (e.g. https://bsky.app/profile/hyzsui.com/post/3ltffzn7p3c26, https://bsky.app/profile/did:plc:plvfzwfp73ezywxils6e6u2n/post/3ltffzn7p3c26)
  • Custom feeds (e.g. https://bsky.app/profile/hyzsui.com/feed/aaapjjmhnkkg6, https://bsky.app/profile/did:plc:plvfzwfp73ezywxils6e6u2n/feed/aaapjjmhnkkg6)
